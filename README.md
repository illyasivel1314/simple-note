<h1 align="center">Simple Note 桌面版</h1>

<p align="center">一个基于 Tauri2.0 & Vue 开发的便笺软件</p>

## 说明

所用技术栈：

- Tauri 2.2.5
- Vue 3.2

已支持的平台：

- Linux
- Windows 11

目前本项目的原始发布地址只有 [**GitHub**](https://github.com/illyasivel1314/simple-note/releases)，其他渠道均为第三方转载发布，与本项目无关！

### 数据同步服务

当前版本暂不支持数据同步，所有数据只会保存在本地，请注意
